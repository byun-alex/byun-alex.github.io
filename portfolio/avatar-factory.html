Avatar Factory

One content engine, swap a file to change the whole channel.

A pipeline that generates short-form video for a synthetic on-camera presenter, end to end, and is built to be reskinned to a new niche by editing a single config file.

Every niche-specific detail (the character, the voice, the angle, the visual rules) lives in one per-persona file the pipeline reads at run time, so launching a new channel is configuration, not a rewrite. The stages are split by cost and reliability: generation produces a face-consistent presenter from a reference image so the same character appears across every scene, a companion editor that Claude drives through tool calls handles the assembly, and a human gate sits before anything is posted.

A teardown of real creators in the space taught me the counterintuitive part: what the presenter says drives results far more than raw generation quality. So the pipeline treats the script as the primary artifact, transcribing a strong in-niche reference and rewriting it with an LLM pre-loaded with the persona. The value is not any single AI model, it is the plumbing that chains a face-identity model, a video generator, a voice model and a programmatic editor into one flow, and the judgment about where to spend metered credits versus where to draft cheap.
