AI Video Editor

An editor an agent drives, not a human.

Claude reads a brief and issues the whole edit as a sequence of tool calls: cut to the strong parts, caption, add motion graphics and B-roll, render. It is the automated assembly stage under my content pipelines.

The generation step of AI content gets all the attention, but the editing step is where the manual hours actually go. This project attacks that. It exposes editing primitives (cut, caption, overlay, B-roll insertion, render) that the agent composes from a brief, so the assembly stage becomes an agent-callable, repeatable operation rather than an afternoon in a timeline app.

Media generation is reached through MCP tool integrations, so the agent can call out for a generated clip mid-edit and fold the result straight into the cut. The output is a rendered video plus a verification pass that checks the result against the brief before it is accepted. It is the shared edit spine under my persona content pipeline: that project makes the footage, this one cuts it.

  • agent tool-calling
  • MCP integration
  • programmatic media assembly
  • verification passes
  • workflow automation

multi-week build

What it actually took. The hard shift was stopping thinking of editing as a creative act and starting to think of it as an API. Once the edit is a set of operations an agent can call and a verifier can check, a whole content pipeline stops needing a human in a timeline. Naming the primitives well was most of the work.
